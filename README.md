# Исследование технологий Vowpal Wabbit и CatBoost в обработке и анализе медицинских данных
 
---
 
## О работе
 
В этой работе сравниваются два подхода к машинному обучению — **CatBoost** и **Vowpal Wabbit** — на двух разных задачах, связанных с медицинскими данными.
 
**Задача 1 — Рекомендация комплементарных медицинских услуг**  
По уже выбранным пациентом анализам модель оценивает, какие дополнительные услуги он может выбрать дальше. Формально это задача бинарной классификации: для каждой услуги-кандидата предсказывается, будет она выбрана или нет.
 
**Задача 2 — Сопоставление наименований медицинских продуктов**  
Модель определяет, относятся ли два названия анализа из разных лабораторий к одному и тому же исследованию (например, «ОАК» и «Общий анализ крови»).

## Данные
 
**Датасет задачи 1** — 22 080 записей, описывающих пары «пациент — услуга-кандидат». Содержит категориальные признаки (возраст, пол, город, профиль) и числовые (количество уже выбранных услуг). Целевая переменная: `target` (1 - пациент воспользовался услугой, 0 — нет).

**Датасет задачи 1 (для корзинного подхода)** - 11 516 записей, сформированных на основе корзин тех же 2 000 пациентов. Для каждого пациента генерируются положительные примеры (услуга убирается из корзины и становится кандидатом) и отрицательные (кандидат - услуга, не входящая в корзину). Содержит список услуг в корзине, код и профиль кандидата, агрегированные признаки. Целевая переменная: `label` (1 - кандидат комплементарен корзине, 0 - нет).
 
**Датасет 2** — 1 784 записи, описывающих пары наименований медицинских исследований из 20 канонических названий и их вариантов написания. Признаки: метрики строкового сходства (расстояние Левенштейна, доля общих слов, разница длин). Целевая переменная: `label` (1 — совпадение, 0 — несовпадение).
