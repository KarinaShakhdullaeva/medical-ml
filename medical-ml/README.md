# Веб-интерфейс к рекомендательной модели

Приложение демонстрирует работу модели CatBoost (корзинный подход): пользователь отмечает анализы пациента, заполняет анкету —
и получает топ-N рекомендованных комплементарных услуг с вероятностями.


## Установка зависимостей

```bash
pip3 install --user -r requirements.txt
```

## Запуск

```bash
python3 -m streamlit run app.py
```

## Как пользоваться

1. **Шаг 1: анкета.** На главной странице укажите возраст, пол и город,
   затем нажмите «Далее».
2. **Шаг 2: каталог.** Сверху сохранённая анкета с кнопкой
   «Изменить». Ниже идёт каталог анализов, сгруппированных по пяти
   диагностическим профилям. Отметьте интересующие исследования
   и нажмите «Добавить в корзину».
3. **Шаг 3: рекомендации.** Под корзиной появится блок «Вам также
   может быть интересно» с пятью рекомендованными услугами. У каждой
   есть кнопка «В корзину» - клик сразу добавляет услугу и в корзину,
   и в каталог сверху, а подборка автоматически пересчитывается.
4. **Технические детали.** В конце страницы свёрнутый блок «Как
   работают рекомендации». Внутри полная таблица всех услуг-кандидатов
   с вероятностями, которые выдаёт модель CatBoost.
